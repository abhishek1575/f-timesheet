✅ 1. Create a Project
POST /projects/create
Role required: SUPER_ADMIN

curl -X POST http://localhost:8080/projects/create \
-H "Authorization: Bearer your_jwt_token_here" \
-H "Content-Type: application/json" \
-d '{
  "name": "New Project",
  "managerId": 2,
  "teamMemberIds": [3, 4]
}'
✅ 2. Assign Manager to Project
PUT /projects/{projectId}/assign-manager/{managerId}
Role required: SUPER_ADMIN


curl -X PUT http://localhost:8080/projects/1/assign-manager/2 \
-H "Authorization: Bearer your_jwt_token_here"
✅ 3. Add Member to Project
PUT /projects/{projectId}/add-member/{userId}
Roles allowed: SUPER_ADMIN, MANAGER


curl -X PUT http://localhost:8080/projects/1/add-member/5 \
-H "Authorization: Bearer your_jwt_token_here"
